# 吱咿 MOD · 调试手册（内部用，勿随包分发）

> 这份文档记录所有调试通道与用法。**后续每次加卡/改机制都要用它**，不要丢。
> 版本：1.0.0（2026-10-21）

---

## 1. 总开关

| 文件 | 作用 |
|---|---|
| `user://zhiji_debug` | 调试总开关。**存在**才启用：F10/指令、敌人血倍率、菜单强制解锁（1.0.0 起菜单解锁改为常开） |

各平台实际路径：

| 平台 | 路径 |

## 2. 指令通道 `user://zhiji_cmd`

- 把指令写进文件（无换行也行），游戏每 0.25s 读一次；
- 读完**立即删除**该文件，避免重复执行；
- 日志关键字：`[zhiji] debug: cmd '<指令>'`。

### 2.1 指令表

| 指令 | 作用 | 备注 |
|---|---|---|
| `next` / `n` | 传送到下一个可走地图节点 | **要求地图界面可见**，否则打印 `travel skipped` |
| `win` | 全体敌人 `LoseHpInternal(999999)` | 还需点一次"结束回合"才结算胜利 |
| `kill` | 全体敌人血量降到 1 | 用来配合真实出牌 |
| `heal` / `hp` | 玩家回满血 | |
| `harvest` / `h` | 收割值 100 + 发一张「收获」 | |
| `guard` / `war` / `balance` | 预设攻/防计数 + 发「童年的终结」 | 用于测三形态大招 |
| `grant`（或按 F10） | 饥饿 100 + 发「童年的终结」 | **唯一**会触发这条分支的指令（9.1.5 起） |
| `cast` | 自动对第一个敌人打出「收获」 | 测大招演出 |
| `play:<ENTRY>` | 自动打出手中指定卡（自动选第一个敌人） | 例：`play:CHILDHOOD_END`、`play:PULSE_AID` |
| `give:<ENTRY>` | 把指定卡加到手牌 | 例：`give:GREEDY_SEARCH` |
| `desc:<ENTRY>` | 打印该卡当前描述、升级状态、变量列表 | 验升级/占位符 |
| `upgrade:<ENTRY>` | 升级手上/抽牌/弃牌/消耗堆里的同名卡 | 验升级数值 |
| `press:<界面文字>` | 按文字点击按钮（支持自定义控件 `OnRelease`） | 例：`press:继续`、`press:放任自流` |
| `arch` | 仅地图可见时：直接进入终幕「建筑师」事件 | 会解锁进阶难度（副作用） |
| `act` | **已禁用** | 直接 `EnterNextAct` 会原生崩溃 |

> ENTRY 命名：单词类名全大写（`FORAGE`），**多单词类名带下划线**（`GREEDY_SEARCH`、`STRENGTH_OFFERING`、`SANGUINE_DEBT`、`THORN_BLOOM`、`BLOOD_BANK`、`GLUTTON_RITE`、`REAP_RITE`）。
>
> 本地化键必须用同一个 entry 小写形式（`sanguine_debt.title`），写错会在日志报
> `LocException: Key=... not found in table=cards`，严重时会导致后续流程异常。

### 2.2 典型流程

**加新卡后自检**
```bash
printf 'give:FORAGE'      > ~/.local/share/SlayTheSpire2/zhiji_cmd   # 进手
printf 'desc:FORAGE'      > ~/.local/share/SlayTheSpire2/zhiji_cmd   # 看描述/变量
printf 'upgrade:FORAGE'   > ~/.local/share/SlayTheSpire2/zhiji_cmd   # 升级
printf 'desc:FORAGE'      > ~/.local/share/SlayTheSpire2/zhiji_cmd   # 对比数值
printf 'play:FORAGE'      > ~/.local/share/SlayTheSpire2/zhiji_cmd   # 打出
```

**测三形态大招**
```bash
printf 'guard' > cmd            # 或 war / balance
printf 'play:CHILDHOOD_END' > cmd
printf 'harvest' > cmd
printf 'cast' > cmd             # 看日志 harvest form=Guard ...
```

**跑图**
```bash
printf 'next' > cmd   # 到下一节点
printf 'win'  > cmd   # 秒杀
# 点"结束回合" → 掉落 → 点"跳过" → 回地图
```

## 5. 调试期间踩过的坑（避免重犯）

1. **不要在地图/房间过渡动画中发 `next`** → 会黑屏卡死；9.1.4 起已加"地图可见"保护；
2. `arch` 在非地图界面直接 `EnterNextAct` 会**原生崩溃**，`act` 指令已禁用；
3. 任何未知指令**不要**触发发牌分支（9.1.5 已限定只有 `grant`/F10）；
4. 手牌上限 10，`give:` 塞太多会溢出到弃牌堆（日志 `not in hand`）；
5. `press:` 依赖按钮/子标签文字，文字改了就失效，需同步更新指令。
