# 吱咿 / 红神 —— 战斗设计与机制（唯一权威文档）

> 任何实现必须以此文档为准；与代码冲突时，先改代码。
> 版本：2026-10-21（v4.0.0 基线）

---

## 1. 核心玩法：一场战斗里是两套牌

```
同一场战斗
├─ 幼年形态：用【你构筑的牌组】（打击/防御/驱力/搏动/缝合/滋养/逃离/预备/童年终结…）
└─ 红神形态：只用【红神牌】（贪食 / 存在的缺失 / 血肉撕裂 / 血肉壁障 / 均衡之刃 / 收获）
```

- 两套牌**互不污染**：
  - 幼年 → 红神：手里的幼年牌**弃入弃牌堆**（正常循环，回落后会再抽到）；
  - 红神 → 幼年：红神牌**移出战斗**（进消耗堆），永不回到牌组；
- 红神形态下**引擎不再抽幼年牌**（拦截 `CardPileCmd.DrawInternal`），每回合固定发 5 张红神牌；
- 回落之后**继续用幼年牌组**（抽牌堆/弃牌堆原样保留，不重置）。

## 2. 形态与流派

| 形态 | 触发 | 牌组 | 能量上限 |
|---|---|---|---|
| 幼年 | 初始 | 构筑牌组 | 3 |
| 红神·战 | 变身时 攻击次数 > 防御次数 | 红神牌（战倾向） | 4 |
| 红神·守 | 变身时 防御次数 > 攻击次数 | 红神牌（守倾向） | 4 |
| 红神·均 | 攻击次数 == 防御次数 | 红神牌（均衡） | 6 |

- 攻/防计数：每打出一张牌，`CardPlay.Target == null` 记防御，否则记攻击；
- **每一场战斗完全独立**：只有生命值跨战斗继承；搏动/饥饿/自助餐/收割/替身/攻防计数/形态
  在战斗开始时全部清零（`combat state reset (hp kept)` 日志）；
- 回落时同样清空饥饿（进度重新累积）；
- 「均」是最强形态（能量 6，红神牌池混合）。

## 3. 资源

| 资源 | 获取 | 作用 |
|---|---|---|
| 搏动 Pulse | 攻击/防御牌附带 | 每 3 点搏动 → +1 饥饿 |
| 饥饿 Hunger | 搏动转化；饕餮(作弊卡) +100 | 达到 100 → 获得「童年的终结」；常态下每回合按饥饿比例自流血 |
| 自助餐 Feast | 变身、击杀、仪典、遗物 | 红神牌伤害加成（`1 + feast/3`，上限 20，可透支 5） |
| 收割 Reap | 红神牌命中 | 每 20 点 → 获得「收获」 |
| 流血 Bleed | 多张牌施加 | 回合结束造成伤害（能力 `BleedPower`） |
| 拼点威力 | 卡面属性 | ≥5 暴击 ×1.5；3~4 ×1.0；≤2 ×0.5 |

关键常数：
- 搏动→饥饿：`3 : 1`
- 饥饿满值：`100`
- 常态自流血：`ceil(maxHp * hunger/100 * 0.10)` 每回合
- 自助餐伤害倍率：`1 + feast/3`（feast 上限 20，允许透支到 -5）

## 4. 变身流程（幼年 → 红神）

触发条件：`Hunger >= 100` 时自动获得「童年的终结」（0 费，可打出）。

打出「童年的终结」后依次执行：

1. 形态判定：`AtkCount vs DefCount` → 战 / 守 / 均；
2. 计算能量上限（4 / 4 / 6）；
3. **手牌替换**：手里幼年牌弃入弃牌堆 → 发 5 张红神牌（按流派选池）；
4. 能量补满到新上限（不是叠加）；
5. 演出：条带变身动画；
6. 遗物「血肉高跷」额外 +25 自助餐。

> 注：变身当回合剩余行动用红神牌继续，回合结束进入标准红神回合。

---

## 5. 回合流程

### 幼年回合
```
回合开始 → 能量重置 3 → 引擎正常抽 5 张（构筑牌组）
        → 饥饿自流血（若饥饿>0）
        → 遗物回复（餐刀+2 / 高跷+1 / 酒杯+3 若有流血）
        → 手牌可正常打出
```

### 红神回合
```
回合开始 → 拦截引擎抽牌（不抽幼年牌）
        → 清掉手里残余红神牌（移出战斗）
        → 发 5 张红神牌
        → 能量重置为上限（4 或 6）
        → 自助餐 +5（高贵品格）
        → 手牌只能用红神牌
```

## 6. 收获（大招）与回落

- 收割满 100 → 获得「收获」；
- 「收获」：5 段打击，每段 `12×骰点 + 自助餐加成 + 扣血/3`；击杀返还 10 自助餐；
- **收获的生命代价与增伤**：打出时扣除**当前生命的 1/2**，其中 **1/3** 加进每段伤害（平衡调整：原为全额，5 段叠加过强）；
- 与回落联动：回落回复"已损失生命的 1/2"并对全体造成**等量伤害** → 形成"以血换输出、再吸血续命"的续航循环；
- **打出「收获」后结束该回合 → 回落幼年形态**：
  - 对全体敌人造成 `max(15, healAmt)` 伤害；
  - 回复等量生命（`healAmt = 缺失生命/2`）；
  - 红神牌全部移出战斗；
  - 自助餐/收割/饥饿/搏动清零；
  - 能量回到 3，下回合抽幼年牌组。

> 回落只在"打出收获并结束回合"时发生；**战斗自然结束不触发回落演出**（下一场战斗按幼年开局）。

## 6.5 特色机制：双用牌（驭力 / 逃离 / 搏动）

这是本 MOD 最核心的原创机制——**同一张牌，拖到敌人身上是攻击，空放（拖到空白处/自己）是防御与资源**。
原版没有这种"一牌两用"的设计。

| 卡 | 指定敌人 | 空放（无目标） |
|---|---|---|
| **驱力** | 8 伤害（升级 11）+ 拼点；命中 +5 搏动（暴击 +7）；击杀回 2/3 生命 | 6 格挡（升级 8）+ 6 搏动（升级 8） |
| **逃离** | 5 伤害（升级 7）+ 4 流血（暴击 6）+ 1 易伤；+4 搏动 | 4 格挡（升级 5）+ 3 搏动（升级 4） |
| **搏动** | 7 伤害（升级 10）+ 消耗最多 6 搏动，每点 +2（升级 +3）伤害 | 7 格挡（升级 10）+ 6 搏动（升级 8） |

设计意图：
- **攻击形态**是"资源产出"（搏动/流血/易伤），**空放形态**是"资源回收"（格挡 + 搏动）；
- 两种形态共享同一张牌，让每一次抽牌都必须做"进攻还是防守"的决策；
- 搭配搏动→饥饿（3:1）的转化，空放也在推进变身进度。

实现要点（代码）：`TargetType.AnyEnemy`，`CardPlay.Target == null` 即判定为空放。

## 9. 实现要点（引擎事实）

1. 抽牌唯一入口 `CardPileCmd.DrawInternal(ctx, count, player, fromHandDraw)`（private static）；
   - 红神形态： prefix 返回自定义 Task（`RedDrawAsync`），由引擎 await，避免时序竞争；
2. 换堆一律用 `CardPileCmd.Add(card, PileType.Hand/Discard/Exhaust, ...)`，**必须 await**（内部 await 补间动画）；
3. 手牌上限 10，超出会被塞进弃牌堆；
4. 红神牌离场 → `Exhaust`，不进弃牌堆；
5. `CardCmd.Discard/Exhaust` 需要 `PlayerChoiceContext`，从 MOD 传 null 会 NRE，故不用；
6. 血条刷新：`NCreatureStateDisplay.RefreshValues()`；
7. 角色选择按钮自定义会导致 PC 端崩溃，暂隔离。

## 12.5 测试台与启动期问题（2026-10-21）

### 已修复的 MOD 缺陷（5.7.0）
- 启动阶段直接 `AddChild` 会失败：`ERROR: Parent node is busy setting up children`。
  受影响：`StartEngineLogTimer()`、`StartAutoTestWatcher()`。
  修复：改为 `tree.Root.CallDeferred(Node.MethodName.AddChild, node)`。
  验证：5.7.0 启动日志中该错误由 2 条降为 0 条。

### 主菜单「单人模式」变灰的原因（引擎逻辑，不是 MOD bug）
`NMainMenu.UpdateTimelineButtonBehavior()`：
- 当 `SaveManager.GetDiscoveredEpochCount() > 0 && !HasRunSave` 时：
  `_timelineButton.Enable()`，同时 `_singleplayerButton.Disable()`/`_multiplayerButton.Disable()`/`_compendiumButton.Disable()`。
- 即：没有进行中的存档、且已解锁纪元时，必须先进「时间线」一次，
  之后单人模式才恢复可用。
- 排查测试台问题时注意：这不是 MOD 导致的按钮失效。

### 远端无头 X 的输入通道
- Xvfb 下鼠标移动可触发悬停，但按下事件经常丢失；`xdotool key --window <id>` 的键盘事件则可稳定送达。
- 结论：菜单导航优先用键盘（Up/Enter/Esc），战斗内直接用调试指令推进。

### 6.6 「童年的终结」的持有规则（1.0.7 定稿）

- 饥饿满 100 → 发放一张「童年的终结」，**自带保留（Retain）**，回合结束不会弃掉；
- 它**离开手牌即从这一局移除**（打出、被弃、被消耗都算），不会进弃牌堆/消耗堆被再摸到；
- 想再获得只能：打出「收获」→ 结束回合**回落** → 饥饿清零 → **重新攒满 100**；
- 红神形态期间不会发放；
- 手牌满 10 张时暂不发放，等有空位再发（避免发出来就被挤掉）。

### 6.7 骰子（1.1.0 起，替代拼点）

- **1d12**：骰面 1~12，**搏动最多 +4**，总点数上限 12；
- 伤害倍率线性：1 点 = **12%**，12 点 = **150%**（每点约 +12.5%）；
- 标签：≥10「爆击」、5~9「命中」、≤4「压制」；
- 表现：屏幕上方的金色大数字先滚动再定格，显示「点数 + 标签 + 百分比」；
- 拼点已从代码与卡面文案中**彻底删除**。

### 6.8 黄金寿衣（立绘）

- 黄金寿衣状态下幼年立绘使用 `gold_idle` 帧（金色披肩，素材由你提供）；
- 所有动画帧统一贴到 **640×320 画布、底边对齐**，修复攻击动作尺寸不同导致立绘上下跳的问题。

### 6.9 状态：饥馑反噬（1.1.4）

- 幼年形态下，无休止饥饿会在**下回合开始时**造成自伤：`最大生命 × 饥饿% × 10%`（向上取整）；
- 该数值作为独立 debuff「饥馑反噬」显示（层数 = 将失去的生命）；
- 计数器 HUD 同步显示「下回合自伤 -N」；
- 红神形态不显示（自伤只发生在幼年）。

## 8. 流血 DOT 流（1.2.x 起，进行中）

### 8.1 解锁方式（规划）

- **第一层第一个随机事件必为「阴暗饭馆」**（1.5.4：`ActModel.PullNextEvent` 后置替换，仅本局第一次、未拿寿衣时生效；日志 `first act event forced -> dark diner`）；

  吃饱了就不饿了 → 获得遗物**黄金寿衣**；红神卡移出本局；**每张幼年体系卡（喂饥饿的那批）换 30 点数**，
  用点数在事件柜台换 **流血基础卡**（割喉/放血/血债，30 点/张，自带卡面悬浮预览）；
  补强卡（千刀/引爆/血宴/血雾/越割越深/回响）只在路上（奖励/商店）获取，不进饭馆；
  柜台列表固定 3 张 + 「离开」，一屏放得下，不会再点不到或退不出去；
- 效果：永久幼年形态（封印无休止饥饿与变身），金色立绘；
- 事件内用点数兑换 DOT 专属卡（下一轮实现）。

## 9. 召唤流（1.5.x 起，进行中）

### 9.1 召唤物模型

- 召唤物以 **Power「食客」** 承载：层数 = 剩余生命（默认上限 30，开饭铃 40）；
- 敌人攻击本体时，食客**优先承受**，但**每次最多挡 8 点**（开饭铃 12 点）——
  这就是对 AOE 的克制：多段/全体伤害会大量穿透，召唤物不能无脑挡；
- 每个**玩家回合开始**，食客自动咬第一个活着的敌人（基础 3 点，开饭铃 +4）。

## 11. DOT 数值现状与调整建议（供拍板）

### 11.2 建议（等你点头再改）

1. 割喉：5 伤 → 4 伤，流血 5 → 6（更偏向 DOT 而不是直伤）；

3. 引爆：层数 ×2 → 层数 ×1.5（配合 70/90 上限）；
4. 千刀：每触发 +1 上限 20 → 15（长战不失控）；
5. 血雾：3 层 → 2 层，但升级 +4（鼓励升级）。
