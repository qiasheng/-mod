## 4. 关键坑（都是这个会话踩过的）

1. **菜单有存栏时，第一项是「继续游戏」**。点它验证"新开局"会拿到旧 run 的牌组（15 张旧卡），曾让我误判牌组代码坏了。验证新开局必须先删 `current_run.save` 并确认菜单是「单人模式」布局（无存栏时 y≈708，有存栏时 继续=675 / 放弃=719）。
2. **`countuse` 日志只对自家卡触发**（驱动/脉搏急救/撑住/喂食…）。原版打击/防御不会打印，用原版卡测"空放"永远没日志。
3. **日志是缓冲写入**（8KB/1s，异常行立即刷）。抓日志前等 3–5 秒，或连发两次命令。
4. **启动要预热约 90 秒**再点击，否则菜单/选人页点击会丢。
5. **AutoSlay 需要完全预热后再启动**，否则它会在"确认角色"卡住并超时退出游戏。
6. **`win` 调试命令**只把敌人打死，战斗有时不会自动结算；要真正结算需手动出牌打死或结束回合。
7. **`t:play:<ID>` 不出牌**（主线程调 `TryManualPlay` 无效），要出牌只能拖拽或点击。
